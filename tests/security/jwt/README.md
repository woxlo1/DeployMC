# JWT security fixtures

Test-only JWT vectors and a localhost JWKS server for the Cloudflare Access verifier.
`io.github.woxlo1.deploymc.core.auth.cloudflare.CloudflareJwtVerifier` consumes these fixtures
through the localhost server in `CloudflareJwtVerifierTest`; no external Cloudflare service is
contacted.

## Safety and determinism

`generate_jwt_vectors.py` creates three 2048-bit RSA keys in memory from fixed throwaway seeds.
Private key material is never written to disk or committed; only public JWK fields appear in
`jwks-initial.json` and `jwks-rotated.json`. Issuers and audiences use the reserved `.test` domain.
The reference time is fixed at `2026-11-22T00:00:00Z`, so `exp` and `nbf` results do not drift.
All generated bytes are ASCII with LF line endings, and the manifest records source SHA-256
digests. Regeneration is byte-identical on every host.

## Vectors

| ID | Category | Initial JWKS | Rotated JWKS | Signal |
|---|---|---|---|---|
| `valid` | valid | accept | accept | Correct RS256 signature, issuer, audience, and time window |
| `expired` | time | `auth.expired` | `auth.expired` | Valid signature, `exp` before the reference time |
| `nbf-in-future` | time | `auth.not-yet-valid` | `auth.not-yet-valid` | Valid signature, `nbf` after the reference time |
| `wrong-aud` | claims | `auth.invalid` | `auth.invalid` | Valid signature, unexpected audience |
| `wrong-iss` | claims | `auth.invalid` | `auth.invalid` | Valid signature, unexpected issuer |
| `alg-none` | algorithm | `auth.invalid` | `auth.invalid` | `alg=none`, empty signature segment |
| `alg-confusion` | algorithm | `auth.invalid` | `auth.invalid` | `alg=HS256` signed with the public RSA modulus as a secret |
| `tampered` | signature | `auth.invalid` | `auth.invalid` | Valid signature reused with modified claim bytes |
| `unknown-kid` | key | `auth.invalid` | `auth.invalid` | Valid signature from a key absent from both JWKS documents |
| `rotated-key` | key | accept | accept | Valid signature from the replacement key retained after rotation |
| `retired-key` | key | accept | `auth.invalid` | Valid signature from the key removed by rotation |

Error codes follow `specification/api/errors.md`. Claim and time failures carry cryptographically
valid signatures so that a future verifier must reject them for the intended claim reason.

## Mock JWKS server

`mock_jwks_server.py` binds only to `127.0.0.1` on an OS-assigned port. It serves the generated
public JWKS at `/cdn-cgi/access/certs` and `/jwks`, returns `Cache-Control` and an `ETag`, and
supports explicit `rotate()`, `reset()`, and `set_unavailable(True)` state changes. The same
changes are available over loopback control paths (`/control/rotate`, `/control/reset`,
`/control/unavailable?value=1`, `/control/requests`) so a non-Python test process can drive them.
The server answers `If-None-Match` with `304` when the current ETag still matches. The `503`
response includes `Retry-After: 1`. No fixed port is used and no external network is contacted.

The per-vector `initial_jwks` and `rotated_jwks` expectations are fixture metadata for two distinct
JWKS documents, not a single verifier-cache contract. A real cache retains keys until its bounded
refresh point, so the product test presents each vector with the document containing its signing
key and tests rotation, ETag revalidation, and staleness separately.

```powershell
python tests/security/jwt/mock_jwks_server.py
```

The command prints the dynamic URL and exits with Ctrl+C. Tests use the class directly with a
context manager instead of launching a separate process.

## Commands

From the repository root:

```powershell
python tests/security/jwt/generate_jwt_vectors.py
python -m unittest discover -s tests/security/jwt -p 'test_*.py' -v
```

The tests verify byte-identical regeneration, manifest digests and expectations, absence of private
key material, header/claim/signature structure, and the mock server's dynamic port, rotation,
reset, cache headers, and unavailability behavior. No JWT verifier, running server, or external
JWKS endpoint was exercised by these fixtures.
